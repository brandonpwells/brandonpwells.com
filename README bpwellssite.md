# brandonpwells.com

Personal site of Brandon Wells. A single self-contained page (`index.html`) served by GitHub Pages.

- `index.html` is the whole site: content, styles, and fonts are all referenced from this one file.
- `CNAME` tells GitHub Pages to serve the site at brandonpwells.com. Do not delete it.

To edit: open `index.html` on GitHub, click the pencil icon, make changes, and commit. The live site updates within a minute or two.

Placeholders still to fill are marked with `class="placeholder"` (they render in red italic).
